---
title: User Support & Control
---
Not all users have the same level of experience, confidence, or familiarity with XR systems. Applications should therefore support accessible and intuitive interactions for both users and instructors. [Onboarding](Onboarding.md) and [Outside Manipulation](Outside-Manipulation.md) address guidance and control from inside and outside the application, while [Super Soldier Syndrome](Super-Soldier-Syndrome.md) provides recommendations to ensure that users behave naturally and authentically within the simulation.
