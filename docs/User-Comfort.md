---
title: User Comfort
---
User comfort is essential for sustained engagement and a positive XR experience. Increased levels of motion sickness are associated with poor user acceptance and training results. \[[15](References.md#ref-15), [68](References.md#ref-68)\] Motion sickness can also reduce cognitive performance, such as reaction times. \[[46](References.md#ref-46), [50](References.md#ref-50)\], while visual fatigue can influence the available working memory resources and thereby directly affect task performance \[[64](References.md#ref-64)\] Providing user comfort is therefore essential for both training and study contexts. This category focuses on reducing physical, visual, and cognitive strain to ensure users can interact comfortably for longer periods. By addressing factors such as [Visual Fatigue](Visual-Fatigue.md), [Motion Sickness](Motion-Sickness.md), and diverse user needs (i.e. [Accessibility](Accessibility.md)), designers can create experiences that are inclusive, safe, and accessible for a wide range of users.
