title: Interaction Design

This category focuses on how users interact with the application and how the system responds to those interactions. The section [Input Methods ](https://github.com/theorchestrator/eac-ux-guidelines/blob/main/Guidelines/Interaction-Design/Input-Methods.md)explores various user input methods recommendations, while [Interaction Feedback](https://github.com/theorchestrator/eac-ux-guidelines/blob/main/Guidelines/Interaction-Design/Interaction-Feedback.md) outlines design choices that help provide clear, meaningful responses to user actions.
